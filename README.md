# 🚀 سامانه ورود و ثبت‌نام فوق مدرن (Modern Auth System)

یک رابط کاربری (UI) نسل جدید، فوق‌العاده مدرن، شیشه‌ای (Glassmorphism) و راست‌چین (RTL) برای صفحات **ورود و ثبت‌نام** با انیمیشن‌های روان و افکت‌های تعاملی سه‌بعدی.

---

## ✨ ویژگی‌های برجسته
- 🌓 **پشتیبانی کامل از تم روز و شب (Dark & Light Mode)** با انیمیشن روان، تغییر رنگ ذرات و ذخیره‌سازی در `localStorage`
- 🌈 **هاله زنده نوری آرورا پشت کارت (Living Aurora Glow)** با گرادیان مخروطی متحرک ۳۶۰ درجه
- 🪐 **مدارهای سایبری فضایی پشت کادر (Cyber Orbit Rings)** با نقاط نوری چرخان
- 🔦 **انعکاس نوری هوشمند متصل به کرسر ماوس (Dynamic Cursor Spotlight)** روی بدنه کارت
- 🌌 **پس‌زمینه ذره‌ای تعاملی با خاصیت گریز از ماوس (Interactive Canvas Particles & Magnetism)**
- 💎 **طراحی شیشه‌ای و نئونی مدرن (Glassmorphism & Neon Glows)**
- 🪐 **افکت تعاملی سه‌بعدی (3D Card Tilt)** با حرکت نشانگر ماوس
- ⚡ **تست سریع اطلاعات کاربری**:
  - نام کاربری: `admin`
  - رمز عبور: `admin`
  - با دکمه اختصاصی پرکردن خودکار فرم
- 🎊 **انیمیشن پرتاب کانفتی (Confetti Celebration)** هنگام ورود موفق
- 🛡️ **داشبورد خوش‌آمدگویی هوشمند** با کارت کاربری و دکمه خروج
- 🔄 **انتقال تب‌ها (ورود / ثبت‌نام)** با اسلایدر قرصی شکل متحرک
- 👁️ **دکمه نمایش/مخفی‌سازی رمز عبور** با آیکون‌های برداری SVG
- 📊 **سنجش زنده قدرت رمز عبور (Password Strength Meter)** در فرم ثبت‌نام
- 🔔 **سیستم اعلان پیام شناور (Toast Notification System)** با حالت‌های موفقیت، خطا و اطلاع‌رسانی
- 📳 **انیمیشن لرزش کارت (Shake Effect)** هنگام وارد کردن اطلاعات اشتباه
- 🔐 **پنجره پاپ‌آپ (Modal) بازیابی رمز عبور**
- 📱 **کاملاً ریسپانسیو (Responsive)** و هماهنگ با موبایل، تبلت و دسکتاپ

```
├── index.html        # ساختار اصلی صفحه و المان‌های HTML

```
